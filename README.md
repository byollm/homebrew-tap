# byollm Homebrew tap

Homebrew tap for the tools built in this organisation. One tap, one formula per
project.

## Install

```bash
brew tap byollm/tap
brew trust byollm/tap
brew install byollm/tap/flocode
```

`brew trust` is required for third-party formulae on Homebrew 7 and newer. To
trust a single formula instead of the whole tap:

```bash
brew trust --formula byollm/tap/flocode
```

Verify the install:

```bash
flocode --version
```

## Available formulae

| Formula | Description |
| --- | --- |
| `flocode` | FloCode, the AI coding agent for the terminal. |

## FloCode

The `flocode` formula installs the `flocode` CLI only. It does not install
Amesh, WireGuard, or the SLIM connector sidecar unless you ask for the sidecar
explicitly.

| Option | Effect |
| --- | --- |
| `--with-slim` | Also install the optional `flocode-slim` connector sidecar used by `flocode connect`. It is published for some platforms only; the install stops with an explicit message where it is missing. |

Every formula points at immutable, per-version release URLs, and Homebrew
verifies each download against the SHA-256 digest recorded in that release's
`checksums.txt`. `brew upgrade` moves to the next published version.

## Updating this tap

`Formula/flocode.rb` is generated by `cmd/flocode-release-tool homebrew-formula`
from a release's `checksums.txt` and published by
`scripts/publish-homebrew-formula.sh` during a stable release. Do not edit a
formula by hand: the next release overwrites it, and the release gate refuses a
formula whose bytes do not match the release checksums.

Each project publishes its own `Formula/<project>.rb` into this tap, so adding
a project means adding a formula, not a second tap repository.

## Uninstall

```bash
brew uninstall flocode
brew untap byollm/tap
```
