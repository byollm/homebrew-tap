# FloCode Homebrew tap

Homebrew tap for **FloCode**, the AI coding agent for the terminal.

The tap installs the `flocode` CLI only. It does not install Amesh, WireGuard,
or the SLIM connector sidecar unless you ask for the sidecar explicitly.

## Install

```bash
brew tap byollm/flocode
brew trust --formula byollm/flocode/flocode
brew install flocode
```

Or install straight from the tap without tapping it first:

```bash
brew install byollm/flocode/flocode
```

Verify the install:

```bash
flocode --version
```

## Options

| Option | Effect |
| --- | --- |
| `--with-slim` | Also install the optional `flocode-slim` connector sidecar used by `flocode connect`. It is published for some platforms only; the install stops with an explicit message where it is missing. |

## What gets installed

Every formula points at immutable, per-version release URLs, and Homebrew
verifies each download against the SHA-256 digest recorded in that release's
`checksums.txt`. `brew upgrade` moves to the next published version.

## Updating this tap

`Formula/flocode.rb` is generated by `cmd/flocode-release-tool homebrew-formula`
from a release's `checksums.txt` and published by
`scripts/publish-homebrew-formula.sh` during a stable release. Do not edit the
formula by hand: the next release overwrites it, and the release gate refuses a
formula whose bytes do not match the release checksums.

## Uninstall

```bash
brew uninstall flocode
brew untap byollm/flocode
```
